# Frontend UI

This app is built with Next.js, TypeScript, and Tailwind CSS.

## Scripts

- `npm run dev` — start the development server
- `npm run build` — build the app
- `npm start` — run the production server

## Setup

1. Copy `.env.example` to `.env` if you need a custom API origin.
2. Install dependencies with `npm install`.
3. Start the app with `npm run dev`.

The frontend expects the backend API to run on `http://localhost:5000/api` unless overridden in `.env`.
